예시 피드예요. 사진을 넣으면 사라져요.

테두리와 숫자가 있는 칸이 올릴 사진이고, 숫자는 올릴 순서예요. 끌어서 순서를 바꾸고, 눌러서 크롭을 맞추세요.

쓰는 법

  1. 지금 피드를 넣어요. 아래에서 인스타 계정을 연결하거나, 프로필 화면을 캡처해서 프로필 스크린샷 가져오기로 넣으면 칸별로 잘려 들어와요.
  2. 올릴 사진 추가로 새 사진을 넣으면 맨 앞에 붙어요.
  3. 올릴 사진을 끌어서 순서를 바꿔요. 휴대폰에서는 살짝 길게 누른 뒤 끌면 돼요.
  4. 실제로 올렸다면 사진을 눌러 게시 완료를 고르세요. 게시된 피드 맨 앞으로 옮겨져요.
  5. 계정이 여러 개면 그리드 위 계정 이름을 눌러 바꿔요. 사진과 순서는 계정마다 따로 저장돼요.

인스타 계정 연결

크리에이터·비즈니스 계정이면 게시된 피드를 바로 불러올 수 있어요. Meta 개발자 대시보드에서 발급한 액세스 토큰을 붙여넣으세요. 토큰은 이 브라우저에만 저장돼요.

토큰 받는 법
  1. 인스타 앱 설정에서 계정을 크리에이터(또는 비즈니스) 계정으로 바꿔요. 계정이 공개 상태여야 해요.
  2. developers.facebook.com에서 앱을 만들어요. 사용 사례는 '기타', 앱 유형은 '비즈니스'를 골라요.
  3. 앱의 제품 목록에서 Instagram을 설정하고, 'Instagram 로그인을 사용한 API 설정' 화면에서 내 계정을 추가해요.
  4. 같은 화면에서 내 계정 옆의 토큰 생성 버튼을 눌러 나온 토큰을 위 칸에 붙여넣어요.
