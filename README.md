# 피드 그리드 플래너

인스타그램에 올리기 전에 3:4 프로필 그리드에서 어떻게 보일지 미리 배치해 보는 개인용 웹앱입니다.

- 올릴 사진을 추가하고 끌어서 순서를 바꿉니다.
- 프로필 스크린샷을 잘라 지금 피드를 가져오거나, 크리에이터·비즈니스 계정의 액세스 토큰으로 게시물을 불러옵니다.
- 인스타 계정을 여러 개 연결하고 그리드 위 드롭다운으로 바꿔 가며 쓸 수 있어요. 사진과 순서는 계정마다 따로 저장돼요.
- 사진과 토큰은 각자의 브라우저(IndexedDB, localStorage)에만 저장되고 서버로 보내지 않습니다.

`index.html` 파일 하나로 동작하며 GitHub Pages로 배포합니다.
